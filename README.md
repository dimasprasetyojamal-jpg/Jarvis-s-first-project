# 🤖 Jarvis Terminal Assistant

Selamat datang di repositori **Jarvis Terminal Assistant**! Ini adalah proyek asisten pribadi berbasis Python yang dijalankan melalui antarmuka terminal/notebook.

## 🚀 Fitur Utama
- 🕒 **Sapaan Otomatis berdasarkan Waktu**: Menyesuaikan sapaan (Pagi, Siang, Sore, Malam) secara akurat.
- 🎯 **Kuis Akademik Interaktif**: Menguji pemahaman materi sekolah secara sistematis.
- 🧮 **Kalkulator Sederhana**: Membantu perhitungan matematika cepat.
- 📓 **Jurnal Tugas Harian**: Mencatat dan mengelola daftar tugas harian.
- 🔍 **Pencarian File Lokal**: Fitur pencarian berkas cepat melalui perintah terminal.

## 🛠️ Teknologi & Environment
- **Bahasa Pemrograman**: Python 3
- **Environment**: Google Colab / Jupyter Notebook
- **Version Control**: Git & GitHub
